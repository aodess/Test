# SPRAYFORM — текущие решения

Дата: 2026-10-03.

## Направление

Небольшая галерея из графитового кирпича. Основной контент — живой HTML, справа реальная скульптура из широких аэрозольных лент. Угольный, тёплый белый, локальные лайм/коралл/кобальт. Без игровой навигации, захвата скролла, звука, автоматического видео, курсора-баллончика и постоянных частиц.

Четыре раздела: hero, три концепта, подход/услуги, контакт. Desktop — примерно четыре экрана по 900 px. На мобильном — высота по содержимому.

## Оценка файлов дизайнера

Это визуальная редакторская оценка, не объективная сертификация «премиальности».

| Файл | Проверка | Решение |
|---|---|---|
| 01 | RGB PNG, 1672×941, почти 16:9. Единый свет, спокойная зона слева, объёмные матовые формы | Хороший эталон и статичный fallback. Не используется вместо 3D |
| 02 | RGB PNG, 1254×1254. Кирпич убедительный, свет уже частично запечён, бесшовность не подтверждена | Используется один раз на каждой стене с clamp. Повторяемых швов нет; карта глубины из теней не создаётся |
| 03 | RGBA PNG, 1254×1254; alpha содержит 0 и 255 с промежуточными значениями | Сохранена прозрачность. Изображение служит плоской декалью, не скульптурой |
| 04 | RGB PNG, 1448×1086, 4:3. Хорошая фактура и единая световая среда | Оставить как художественную обложку PULSE |
| 05 | RGB PNG, 1448×1086, 4:3. Самая спокойная композиция серии, ясный силуэт | Оставить как обложку FORM |
| 06 | RGB PNG, 1448×1086, 4:3. Кольцо и прозрачная орбита сочетаются с темой цифрового продукта | Оставить как обложку ORBIT |
| 07 | RGBA PNG, 1254×1254. Настоящий alpha, но крупные остаточные пиксели и артефакты внутри знака | Не публиковать растр. Создан чистый однокрасочный SVG по мотивам широких соединённых штрихов и капли |

Общий вывод: серия подходит для единой галереи. Слабое место — обложки близки по художественному языку и сами по себе ещё не доказывают качество веб-интерфейсов. На сайте это честно обозначено: художественные концепты, не кейсы клиентов и не экраны готовых продуктов. Замены сейчас не нужны. Для будущего реального портфолио следующий полезный материал — экраны реализованных сайтов с подтверждёнными задачами, а не ещё одна абстрактная скульптура.

## Логотип

Монограмма SVG имеет ясную общую массу, S-образное широкое движение, объединённый F и маленькую каплю. Wordmark — настоящий текст Space Grotesk. Никакого знака зарегистрированной торговой марки не добавлено. Favicon — адаптация на лаймовом квадрате.

## Открытые пункты

1. Владелец должен подтвердить контакт SPRAYFORM: email или Telegram. Данные из массажного бизнеса не перенесены.
2. Требуется создать новый GitHub repository. Текущий connector не имеет такой операции. Код готов к загрузке; остальные репозитории не затронуты.
3. После создания repository — отдельный Railway deployment и проверка публичного URL.
4. Физический iPhone и реальная мобильная GPU не проверены. Были браузерные эмуляции и программный WebGL.

Этот файл можно использовать как общий документ решений для двух чатов проекта. Автоматический обмен сообщениями между чатами не настраивался.
