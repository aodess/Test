# SPRAYFORM — проверка

2026-10-03. Проверяется production-сборка через собственный Node static server, не dev/preview.

## Результаты

- `astro check`: 0 errors, 0 warnings, 0 hints.
- `astro build`: успешно, 4 статические страницы. Сборщик сообщает о крупном несжатом 3D chunk; он загружается отдельным idle-island и передаётся со сжатием. Есть предупреждение зависимости Drei о CJS-совместимости Three; runtime ошибок не обнаружено.
- Playwright: шесть размеров — 360×800, 390×844, 768×1024, 1440×1000, 844×390, 1024×768. Горизонтального переполнения нет. Навигация и CTA проверены.
- Три окна концептов: Enter, Tab/Shift+Tab, Escape, кнопка закрытия, возврат фокуса и блокировка фоновой прокрутки. Исправлен уход фокуса из окна с единственной кнопкой.
- axe-core WCAG 2 A/AA и 2.1 AA: главная и открытый диалог — без выявленных нарушений после исправления контраста нижнего wordmark. Это автоматическая проверка, не полная сертификация доступности.
- Reduced motion: статичный WebGL canvas не меняется при движении мыши.
- Реально заблокированный `getContext('webgl2')`: текст и fallback видны, окна доступны.
- JavaScript отключён: основной HTML читается, ссылка проекта открывает самостоятельную статическую страницу.
- Touch: `pan-y pinch-zoom`, локальный поворот, сброс по `pointercancel`, отсутствие `maximum-scale` / запрета масштабирования.
- Сервер: `/health` 200, неизвестный адрес 404, правильные MIME для HTML, AVIF, WOFF2, ETag/304.
- 03/07: настоящие RGBA PNG, alpha 0–255. Финальная декаль сохраняет alpha. Растровый 07 заменён SVG.
- В локальном Golos Text проверены все 66 прописных и строчных русских букв, включая Ё/ё. Отсутствующих символов нет.

## Измерения

Среда: Chromium 141 headless, SwiftShader (программный WebGL), viewport 1440×1000. Это не реальный iPhone и не мобильная GPU.

Во время движения указателя: медианный интервал подачи кадров около 36 мс, p95 около 61 мс после адаптивного снижения DPR. Это CPU-side submission timing, не аппаратно измеренные GPU-presented FPS. Гарантия 60 fps не заявляется.

В покое: 0 новых draw calls за 500 мс. После выхода сцены за экран: 0 за 500 мс. Скрытая вкладка переводит frame loop в `never` по `visibilitychange`.

Переданные ресурсы после загрузки hero и 3D, до открытия окон: около 1.17 МБ (без HTML), из них изображения 0.76 МБ, JavaScript 0.33 МБ. Fallback hero AVIF 78 КБ, 3D island около 219 КБ Brotli; все ресурсы — с того же сервера. Все оригинальные PNG при просмотре сайта не загружаются.
